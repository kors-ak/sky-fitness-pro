# SkyFitnessPro

_Учебный проект по frontend-разработке_

Веб-приложение для онлайн-тренировок. Сервис позволяет изучать каталог фитнес-курсов, добавлять их в свой профиль, проходить тренировки с видео и отслеживать свой прогресс.

🚀 **Live Demo:** [https://sky-fitness-pro-eta.vercel.app/](https://sky-fitness-pro-eta.vercel.app/)

## Функциональность

- Регистрация и вход в аккаунт, валидация полей форм и отображение ошибок API.
- Каталог курсов на главной странице.
- Страница курса с описанием.
- Добавление курсов в свой профиль и удаление из него.
- Личный кабинет: данные пользователя и «Мои курсы» с прогрессом по каждому.
- Выбор тренировки во всплывающем окне.
- Страница тренировки с видеоплеером и списком упражнений.
- Сохранение и сброс прогресса тренировки, перезапуск курса с нуля.
- Скелетоны загрузки для карточек курсов, страницы курса и страницы тренировки.
- Отдельная страница для несуществующих маршрутов (404).
- Адаптивная вёрстка для десктопа, планшета и мобильных устройств.

## Архитектурные решения

- **Глобальное состояние** реализовано с помощью Redux Toolkit. В сторе хранятся все курсы, курсы пользователя, прогресс по тренировкам, данные пользователя и отдельные флаги загрузки для разных операций (получение списка, добавление и удаление курса, загрузка прогресса).
- **Работа с API** вынесена в отдельный слой сервисов (`src/services`). Запросы выполняются через Fetch API, авторизация обрабатывается отдельно.
- **Маршрутизация** построена на Next.js App Router. Динамические маршруты `/course/[nameEN]` и `/course/[nameEN]/workout/[id]` отвечают за страницы курса и тренировки соответственно, несуществующие адреса попадают на `not-found`.
- **Компонентная архитектура**: интерфейс разделён на переиспользуемые компоненты в `src/components` (карточки курсов, видеоплеер, блок прогресса, попапы, скелетоны).
- **Инициализация данных** вынесена в отдельные компоненты (`src/components/initialization`): они загружают данные при старте приложения и при переходе на страницы курса и тренировки.
- **Состояния загрузки** обрабатываются скелетонами на базе общего компонента `Skeleton`, размеры которых совпадают с реальными элементами, чтобы вёрстка не прыгала.
- **Пользовательские хуки** (`src/hooks`) инкапсулируют логику работы с курсами и прогрессом: добавление и удаление курса, сохранение и сброс прогресса, расчёт процента выполнения.
- **Стилизация** выполнена с помощью CSS Modules, что изолирует стили компонентов. Для условных классов используется `classnames`.
- **Типизация**: общие типы данных (курсы, тренировки, прогресс) вынесены в `src/sharedTypes`.
- **Тестирование**: Jest используется для проверки вспомогательных функций и бизнес-логики.
- **Качество кода** поддерживается ESLint и Prettier.

## Структура проекта

```text
src/
├── app/                # Страницы, layouts и not-found (Next.js App Router)
├── components/
│   ├── features/       # Основные UI-компоненты: карточки курсов, видеоплеер, блок прогресса
│   ├── initialization/ # Инициализация курсов и прогресса пользователя
│   ├── popups/         # Всплывающие окна
│   └── skeletons/      # Cкелетоны загрузки
├── hooks/              # Пользовательские React-хуки
├── services/           # Запросы к API и обработка авторизации
├── sharedTypes/        # Общие типы TypeScript
├── store/              # Redux store
└── utils/              # Вспомогательные функции и их тесты
```

## Установка и запуск

### Клонирование репозитория

```bash
git clone https://github.com/kors-ak/sky-fitness-pro.git
cd sky-fitness-pro
```

### Установка зависимостей

```bash
npm install
```

### Запуск проекта

```bash
npm run dev
```

Приложение будет доступно по адресу:

```text
http://localhost:3000
```

### Другие команды

```bash
npm run build   # production-сборка
npm run start   # запуск production-сборки
npm run lint    # проверка кода ESLint
npm test        # запуск тестов Jest
```
